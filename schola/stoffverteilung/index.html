Eine Kalender-ID verbindet das Schuljahr aus Stundenplan. Unterrichtstermine, Ferien, Fächer und Klassen werden daraus übernommen; Ihre Planung bleibt als eigene lokale Arbeitsfassung gespeichert.

Kalenderdaten werden beim Öffnen neu gelesen. Planungsinhalte verbleiben im Browser und können als JSON exportiert werden.
