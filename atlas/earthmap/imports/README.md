# EarthMap Importordner

Lege hier GeoJSON, KML/KMZ oder gezippte Shapefiles ab, die über den Tab „Importieren“ in EarthMap ausgewählt werden sollen.

Hinweis: Der Browser kann aus Sicherheitsgründen nicht in jedem Kontext automatisch genau diesen Ordner öffnen. Der Ordner ist als feste Projektablage vorbereitet; für sehr große Dateien folgt als nächster Schritt eine Referenz-/Archivlogik, damit Geometrien nicht vollständig im Browser-Speicher landen müssen.
